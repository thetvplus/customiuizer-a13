# A13 独立审查

采用用户指定的 base/head 或工作区差异，已有可信的范围直接使用。只读检查 Git、相关源码、测试和已有证据。评审期间禁止改源码、测试、配置、分支或工作树，禁止提交、推送和合并。

沿修改的调用链检查触发、原方法与回退、状态和所有者，必要时展开相邻调用者。关注崩溃、数据错误、权限边界、重复安装、释放遗漏、回调次序、ROM / ClassLoader 和实际热路径成本。对资源与 R8 问题查消费链。证据基于 [A13 的分级](../../../COMPATIBILITY.md#证据等级)；宿主测试和历史样本有各自的成立范围。

报告由差异引入或加重的缺陷，按 P0–P3 排序。每项给出文件及行号、触发条件、影响、直接证据与最小修复建议。排除格式偏好、推测性微优化和无关积压问题。查无确证时说明已审范围内无确定缺陷，列出具体待验项。审查结果保留在回复或指定评审界面。
