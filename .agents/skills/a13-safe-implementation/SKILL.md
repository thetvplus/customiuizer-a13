# A13 安全实施

遵循 [AGENTS](../../../AGENTS.md)，沿用当前任务已确认的授权、分支和证据。

1. 沿实际触发、调用链和所有者定位失败。私有成员不确定时复用 [DexSQL 查询](../../../tools/dexsql/README.md)，确认 ROM/API、宿主组件和 DEX 可用性后查定义及调用语义。
2. 做最小可回退改动。优先取消无效工作或复用系统能力。稳定成员提前准备，功能按需激活，输入变化再执行更新。检查异常、原方法次数、旧偏好和原生回退。
3. 按 [AGENTS](../../../AGENTS.md#验证与协作)审阅 diff 和选测。资源问题检查压缩产物，记录证据覆盖范围和待验项。
